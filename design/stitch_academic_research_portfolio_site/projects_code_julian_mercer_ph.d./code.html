Projects & Code

A selection of open-source research software, reproducible benchmark codebases, and experimental toolkits developed for machine learning and acoustic modeling.

5 repositories indexed
2023–Present Active

OpenAcoustic: Modular Speech Representations in PyTorch

A modular, high-throughput research framework implementing self-supervised speech encoders with native multi-GPU DDP training, custom CUDA kernels for streaming attention, and extensive evaluation suites for phoneme error rate and representation probing.

Taxonomy: Speech Recognition Representation Learning Deep Learning
Stack: Python, PyTorch, CUDA, TorchAudio, Hugging Face
[GitHub Repository] · [Documentation] · [Paper (Interspeech '23)]
2024 Active

Distill-Wav: Low-Latency Sequence Distillation for Streaming ASR

An implementation of knowledge distillation methods specifically designed for transducer-based streaming acoustic models, achieving 4.2x inference speedup on ARM CPU targets with less than 0.8% relative WER degradation.

Taxonomy: Speech Recognition Model Compression Distillation
Stack: Python, C++, ONNX Runtime, LibriSpeech Benchmark
[GitHub Repository] · [Preprint] · [Benchmark Suite]
2023 Completed

Neural-Align: Differentiable Monotonic Alignment for Sequence Tasks

A fast CUDA implementation of the forward-backward dynamic programming algorithm for CTC and RNN-Transducer loss formulations, featuring memory-efficient gradient checkpointing.

Taxonomy: Alignment Algorithms CUDA Kernels Optimization
Stack: C++, CUDA, PyTorch C++ Extension
[GitHub Repository] · [PyPI Package] · [Paper]
2022–2023 Completed

LatentGrammar: Diagnostic Probing Tools for LLM Representations

Diagnostic probes and geometric subspace alignment tools to analyze syntactic and semantic tree abstractions encoded in the intermediate layers of decoder-only transformer architectures.

Taxonomy: Natural Language Processing Interpretability Probing
Stack: Python, PyTorch, SciPy, Matplotlib
[GitHub Repository] · [Notebook Tutorial] · [ACL Findings '23]
2022 Archived

AcousticBench: Reproducible Evaluation Harness for Robust Audio

A lightweight benchmarking harness that systematically evaluates audio model robustness across 14 synthetic noise distributions, room impulse response simulations, and packet loss conditions.

Taxonomy: Benchmarking Audio Evaluation Reproducibility
Stack: Python, SoundFile, NumPy, Docker
